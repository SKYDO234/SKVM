  2. Store it locally:

{# Auth #}

{{ icon('shield', 16) }} Authentication

Session ∨ Bearer

Bearer (CI, scripts, Terraform)

Authorization: Bearer <sk_XXXX.yyyyy> X-API-Key: <same value> # legacy header GET /api/v1/summary?token=<sk_…> # query fallback

Tokens carry a prefix (sk_xxxx) visible in audit logs; only the hash is stored. IP allowlists and expiry are optional.

Cookie (in-panel JS)

fetch('/api/v1/servers', { headers: { 'X-CSRF-Token': document.querySelector('meta[name=csrf-token]').content } })

Session cookies are HttpOnly, SameSite-Lax, skvm_session and revocable individually under Account → Sessions.
